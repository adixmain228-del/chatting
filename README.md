# Позывной — простой чат для друзей

Прототип чата без регистрации и без своей базы данных. Один человек создаёт
комнату, получает 6-символьный код, скидывает его друзьям — они по этому коду
заходят в тот же чат.

## Как это устроено

- **Next.js** (App Router) — одно приложение, фронтенд и API вместе.
- **Хранилище — Redis через Vercel Marketplace** (`lib/store.js`, клиент
  `@upstash/redis`). Отдельную базу данных поднимать и администрировать
  не нужно — подключается прямо из панели Vercel в несколько кликов (шаг 3
  ниже). Раньше для этого был отдельный продукт «Vercel KV», но в конце
  2024 года Vercel убрал его и перенёс всё в маркетплейс — сейчас нужный
  пункт называется **Upstash**.
- Обновление сообщений — простым **поллингом** раз в 2 секунды (без веб-сокетов,
  чтобы без проблем работать на бессерверном хостинге).
- Имя пользователя хранится в `localStorage` браузера — авторизации нет,
  это чат для своих, а не публичный сервис.

### Почему нельзя было обойтись без внешнего хранилища

Первая версия хранила данные прямо в памяти сервера — но на Vercel каждый
файл `route.js` (создание комнаты, вход по коду, сообщения) разворачивается
как **отдельная serverless-функция со своей собственной памятью**. Комната,
созданная в одной функции, была физически не видна другой — из-за этого вход
по «правильному» коду не срабатывал, а отправленные сообщения никуда не
сохранялись. Это гарантированное поведение архитектуры Vercel, а не глюк,
поэтому нужно общее хранилище, доступное сразу всем функциям.

### Ограничение, о котором стоит знать

Комнаты и сообщения автоматически удаляются после **суток без активности**
(это специально, чтобы не копить данные на бесплатном тарифе). Для чата
с друзьями это не помеха — при следующем сообщении отсчёт начнётся заново.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

Без подключённого Redis локально работает резервное хранилище в памяти —
для разработки в одиночку этого достаточно.

## Деплой на Vercel (бесплатно)

1. Залейте эту папку в свой репозиторий на GitHub.
2. Зайдите на https://vercel.com → **Add New → Project** → выберите репозиторий
   → нажмите **Deploy** (ничего не меняя в настройках).
3. **Обязательный шаг** — подключите Redis:
   - откройте задеплоенный проект в панели Vercel → вкладка **Storage**
     → **Browse Storage** (или **Create Database**);
   - в списке **Marketplace Database Providers** выберите **Upstash**
     («Serverless DB (Redis, Vector, Queue, Search)») — именно этот пункт
     заменил старый «Vercel KV»;
   - при создании выберите тип **Redis** (не Vector / Queue / Search) —
     бесплатного тарифа достаточно для чата с друзьями;
   - на последнем шаге нажмите **Connect Project**, чтобы Vercel сам прописал
     переменные окружения — они появятся под именами `KV_REST_API_URL` /
     `KV_REST_API_TOKEN` либо `UPSTASH_REDIS_REST_URL` /
     `UPSTASH_REDIS_REST_TOKEN` (зависит от версии интеграции) — код
     в `lib/store.js` понимает оба варианта, ничего вручную настраивать не надо.
4. После подключения Vercel предложит **Redeploy** — нажмите его, чтобы
   переменные окружения подхватились.
5. Получите ссылку вида `https://ваш-проект.vercel.app` — скиньте её друзьям.

Без выполнения шага 3 сайт откроется, но создание комнат и чат работать
не будут — это тот самый баг, из-за которого писалась эта версия README.

## Как пользоваться

1. Один человек открывает сайт → вкладка **«Создать»** → вводит своё имя →
   получает код комнаты (например `XK4P9L`).
2. Остальные открывают тот же сайт → вкладка **«Войти по коду»** → вводят
   код и своё имя.
3. Все видят, кто сейчас на связи, и обмениваются сообщениями в одной комнате.

## Возможные доработки

- Показ «печатает…».
- Личные сообщения между двумя пользователями внутри комнаты.
- Реакции на сообщения эмодзи.
