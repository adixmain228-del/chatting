# Позывной — простой чат для друзей

Прототип чата без регистрации и без базы данных. Один человек создаёт комнату,
получает 6-символьный код, скидывает его друзьям — они по этому коду
заходят в тот же чат.

## Как это устроено

- **Next.js** (App Router) — одно приложение, фронтенд и API вместе.
- **Хранилище — прямо в памяти сервера** (`lib/store.js`), без Postgres/Redis/Mongo и т.д.
- Обновление сообщений — простым **поллингом** раз в 2 секунды (без веб-сокетов,
  чтобы без проблем работать на бессерверном хостинге вроде Vercel).
- Имя пользователя хранится в `localStorage` браузера — авторизации нет,
  это чат для своих, а не публичный сервис.

### Важное ограничение (осознанный компромисс)

Так как это бессерверные функции Vercel, а не постоянно работающий сервер,
данные в памяти:

- **пропадают при каждом передеплое** проекта;
- могут **сброситься после долгого простоя** (если функция «уснёт»);
- в теории, при очень большой нагрузке несколько «холодных» копий функции
  могут временно видеть чуть разные данные — для чата из нескольких друзей
  на практике это не заметно.

Если захотите сделать чат надёжнее и «вечным» — самый простой следующий шаг —
подключить **Vercel KV** (бесплатный тариф, настраивается в два клика в
панели Vercel, без своего сервера БД) и заменить содержимое `lib/store.js`
на запросы к нему, оставив все API-роуты как есть.

## Запуск локально

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Деплой на Vercel (бесплатно)

Вариант А — через сайт:

1. Залейте эту папку в свой репозиторий на GitHub.
2. Зайдите на https://vercel.com → **Add New → Project**.
3. Выберите репозиторий, ничего не меняя в настройках нажмите **Deploy**.
4. Через минуту получите ссылку вида `https://ваш-проект.vercel.app` —
   скиньте её друзьям.

Вариант Б — через терминал, без GitHub:

```bash
npm i -g vercel
vercel
```

Следуйте подсказкам — Vercel сам всё соберёт и задеплоит.

## Как пользоваться

1. Один человек открывает сайт → вкладка **«Создать»** → вводит своё имя →
   получает код комнаты (например `XK4P9L`).
2. Остальные открывают тот же сайт → вкладка **«Войти по коду»** → вводят
   код и своё имя.
3. Все видят, кто сейчас на связи, и обмениваются сообщениями в одной комнате.

## Возможные доработки

- Показ «печатает…».
- Личные сообщения между двумя пользователями внутри комнаты.
- Реакции на сообщения эмодзи.
- Подключение Vercel KV для постоянного хранения истории.
